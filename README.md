# 🚀 Featured Projects

### Pokepython 🐍🎮
A **text-based RPG** built entirely in Python inspired by the Pokémon games.

Features:
- Starter Pokémon selection
- Wild Pokémon battles
- Capture mechanics
- Pokémon evolution
- Legendary encounters

Tech stack:
- Python

---

### SysCall 💻🔧
A **full-stack web platform** that connects users who need technical support with available technicians.

Developed as a final project for the **Experiência Criativa** course.

Features:
- Client-server architecture
- Dynamic pages rendered with templates
- B2B and B2C support model

Tech stack:
- FastAPI
- MariaDB
- HTML
- CSS
- JavaScript
- Jinja2

---

### Water Enhanced 🌊⛏️
A **Minecraft mod** developed using the **Fabric Modding API**.

The project expands the aquatic side of the game by introducing new mechanics, materials, and gameplay elements related to oceans and water biomes.

Besides gameplay improvements, the project was also used to practice **Object-Oriented Programming concepts** by implementing custom entities, items, blocks, and game systems integrated with the Minecraft engine.

Tech stack:
- Java
- Fabric API
- Minecraft Modding
